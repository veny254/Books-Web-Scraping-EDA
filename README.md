

\# Books Web Scraping \& Exploratory Data Analysis



\## Project Overview

An end-to-end Python project that collects book information from \[Books to Scrape](https://books.toscrape.com/), cleans the collected data, performs exploratory data analysis, and generates visual reports.



\## Technologies Used

\- Python

\- BeautifulSoup

\- urllib

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- CSV



\## Key Features

\- Scrapes book titles, prices, ratings, availability, and categories.

\- Handles pagination and HTTP request errors.

\- Cleans and validates the collected dataset.

\- Removes duplicate records and handles missing values.

\- Performs statistical and exploratory data analysis.

\- Generates visualizations of prices, ratings, categories, and price-rating relationships.

\- Exports cleaned datasets, analytical summaries, and a final report.
